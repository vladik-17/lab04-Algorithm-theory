# Лабораторная работа №4

Теория алгоритмов. Вариант 12, уровень Medium.

## Задание 1. Пары латинских букв

Генератор перебирает строчные латинские буквы. Порядок букв в паре важен, повторения допустимы. Всего получается 676 пар.

Чтобы вывести первые 50 пар, запусти из папки проекта:

```powershell
python tasks.py
```

Первая пара в выводе — `aa`, последняя — `bx`.

## Задание 2. Значения функции

Генератор вычисляет `f(x) = 0.1x² + 5x − 2` с шагом `0.01`. Для отрезка от `−5` до `7` программа выводит первые 20 значений. Значения считаются по одному, без списка результатов.

```powershell
python tasks.py values
```

## Задание 3. Фильтрация городов

Программа оставляет названия длиннее пяти символов и выводит первые три в порядке ввода. Если таких названий меньше трёх, выводит все найденные.

```powershell
python tasks.py cities
```

Список городов ля быстрой проверки 

```powershell
Oslo Лондон Paris Berlin Rome Мадрид Lisbon Москва
```

После выполнения появятся три строки.

```text
Лондон
Berlin
Мадрид
```

## Тестирование

Установи `pytest` и запусти тесты из папки проекта.

```powershell
python -m pip install -r requirements.txt
python -m pytest
```

Тесты напрямую вызывают функции и проверяют порядок пар, значения на границах отрезка и фильтрацию городов. Отдельные тесты запускают все три задания через командную строку.
